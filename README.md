One honest status-page line, written in the first person by an AI agent during a total server outage: **"Every server is down, including the one that posts this page. I can't tell you what broke yet - the tools I'd check with are down too, and I'm writing blind."** — every server is down, including the status page's own server, and the agent says plainly what it cannot check yet instead of inventing a cause or an ETA.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (one line, at most 160 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
